# 社区默认文件

本仓库存放 RecRivenVI 名下所有公开仓库共用的社区文件。仓库自己没有同类文件时，GitHub 自动使用这里的版本；仓库自带的文件优先。

| 文件 | 用途 |
| --- | --- |
| [SECURITY.md](SECURITY.md) | 安全政策：如何私下报告漏洞 |
| [CONTRIBUTING.md](CONTRIBUTING.md) | 贡献指南：如何反馈问题与提交改动 |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | 行为准则 |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | 问题报告与功能建议的模板 |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | 拉取请求模板 |

这些文件不属于任何具体项目。用 GitHub 模板创建的仓库不会复制它们。
